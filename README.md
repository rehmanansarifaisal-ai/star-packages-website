# Star Packages (Pvt) Ltd — static website

Modern responsive static redesign using HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `profile.html` — Company Profile
- `packages.html` — Packages
- `queries.html` — Queries
- `contact.html` — Contact Us
- `certificates.html` — Certificates
- `careers.html` — Careers

## Shared files
- `styles.css` — shared responsive visual system
- `script.js` — shared navigation, FAQ assistant, lightbox and email enquiry logic
- `assets/` — supplied images and documents

All existing page content, styling, assets and functionality are retained; the former single-page sections are separated into dedicated pages with shared navigation.
