## Overview

Star Packages is a professional travel and tourism website created to present the company, its services, travel packages, professional credentials, and enquiry channels in a polished and modern digital experience.

The interface combines a refined editorial visual style with responsive layouts, immersive imagery, interactive components, smooth transitions, and persistent light/dark theme support.

## Highlights

- Elegant, responsive design across desktop, tablet, and mobile screens
- Light mode and dark mode with persistent theme preference
- Animated hero slideshow featuring Makkah imagery
- Smooth scroll-reveal and micro-interaction effects
- Interactive navigation, cards, buttons, FAQs, and enquiry elements
- Dedicated service presentation for Travel & Tourism, Umrah & Hajj, Reservations, and Business Travel
- Company profile and professional credentials presentation
- Package listings and certificate showcase
- Dedicated queries, contact, and careers pages
- Social contact shortcuts with recognisable platform icons
- Image lightbox interactions and responsive media presentation
- Shared styling and scripting for a consistent experience across pages

## Design Direction

The website uses a sophisticated travel-oriented visual language built around:

- Deep green, warm gold, and neutral tones
- Large editorial-style typography
- Makkah-focused photography and immersive imagery
- Generous spacing and structured content sections
- Rounded cards with subtle depth and hover states
- Motion used to guide attention without overwhelming the content

## Interaction & Motion

The interface includes subtle animation throughout the browsing experience, including:

- Scroll-triggered section reveals
- Staggered content entrances
- Hover elevation and card motion
- Interactive navigation states
- Button and link micro-interactions
- Hero image transitions and slideshow controls
- Expandable FAQ items
- Image lightbox presentation
- Theme transitions between light and dark modes
- Responsive behaviour for touch devices

## Getting Started

No package installation or build pipeline is required.

### 1. Clone the repository

```bash
git clone <repository-url>
cd <repository-directory>
```

### 2. Open the website

Open `index.html` in a modern browser.

For a local development server, any simple static server can be used. For example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customisation

Most visual and interactive behaviour is centralised in the shared files:

- `styles.css` — layout, responsive behaviour, themes, animations, components, and visual states
- `script.js` — navigation, theme persistence, slideshow behaviour, FAQs, lightbox interactions, and enquiry helpers
- `assets/` — photography, package artwork, certificates, and supporting media

Page-specific copy and structure are contained in their respective HTML files.
